Linux常用命令

一个记录Linux常用命令的博客。

Linux常用命令

chmod

可以使用a,u,g,o指定给什么用户修改权限,augo分别表示所有人(all)、用户(user)、组(group)、其他用户(other)示例:
1.给所有用户加上x权限: chmod a+x hello
2.给所有用户去除x权限: chmod a-x hello
3.给拥有者加上x权限: chmod u+x hello
4.给拥有者去除x权限: chmod u-x hello
数值表示：如 -rwxrwx—
owner=rwx=4+2+1=7
group=rwx=4+2+1=7
others=—=0+0+0=0
所以在设置权限时，该文件的权限数字就是 770.

ifconfig

启动关闭指定网卡 ifconfig eth0 up/down
配置IP地址(如给eth0网卡配置IP地址,加上子掩码,加上个广播地址) ifconfig eth0 192.168.1.56 netmask 255.255.255.0 broadcast 192.168.1.255
启用和关闭ARP协议 ifconfig eth0 arp/-arp

date

显示当前时间 date
显示完整的时间 date ‘+%D’
显示数字日期 date ‘+%x’
格式化输出 date +”%Y-%m-%d”
输出昨天日期： date -d “1 day ago” +”%Y-%m-%d”

kill

终止 PID 为 1234 的进程： kill 1234
强制终止 PID 为 1234 的进程： kill -9 1234
向 PID 为 1234 的进程发送 SIGSTOP： kill -s SIGSTOP 1234
杀死指定用户所有进程: kill -9 $(ps -ef | grep hnlinux) //方法一 过滤出hnlinux用户进程 ； kill -u hnlinux //方法二
Tip: kill 命令是向进程发送信号，kill 不是杀死的意思，-9 表示无条件退出，但由进程自行决定是否退出，kill -9 终止不了系统进程和守护进程的原因。
如果kill -9终止不了，说明：1）这个进程是僵尸进程；2）这个进程处于”核心态”。

history

查看完整历史记录 history
查看最近 N 条记录 history N
找回忘记的命令 history | grep “apt install”
查看你的命令历史，找出最近使用的5条git命令 history | grep git | tail -5

grep

在文件 file.txt 中查找字符串 “hello”，并打印匹配的行： grep hello file.txt
在文件夹 dir 中递归查找所有文件中匹配正则表达式 “pattern” 的行，并打印匹配行所在的文件名和行号： grep -r -n pattern dir/
在当前目录中，查找后缀有file字样的文件中包含test字符串的文件，并打印出该字符串的行。此时，可以使用如下命令： grep test *file

find

查找当前目录下名为file.txt的文件： find . -name file.txt
将当前目录及其子目录下所有文件后缀为.c 的文件列出来: find . -name “*.c”
将当前目录及其子目录中的所有文件列出： find . -type f
查找 /home目录下大于 1MB 的文件： find /home -size +1M
查找 /var/log 目录下在 7 天前修改过的文件： find /var/log -mtime +7

mv

将文件 aaa 改名为 bbb: mv aaa bbb
将info目录放入logs目录中(如果logs目录不存在，则该命令将info改名为logs): mv info/ logs
将 /usr/runoob 下的所有文件和目录移到当前目录下： mv /usr/runoob/* .

locate

查找 passwd 文件，输入以下命令： locate passwd
搜索 etc 目录下所有以 sh 开头的文件： locate /etc/sh

passwd

修改用户密码 passwd runoob //设置runoob用户的密码
显示账号密码信息 passwd -S runoob
删除用户密码 passwd -d lx138

tar

创建归档文件：将文件file1、file2和directory打包到一个名为 archive.tar 的归档文件中： tar -cvf archive.tar file1 file2 directory
解压归档文件：解压名为 archive.tar 的归档文件。 tar -xvf archive.tar
指定压缩格式
z : 使用 gzip 压缩。tar -czvf archive.tar.gz directory 解压：tar -xzvf archive.tar.gz
j: 使用 bzip2 压缩。tar -cjvf archive.tar.bz2 directory 解压：tar -xjvf archive.tar.bz2
J: 使用 xz 压缩。 tar -cJvf archive.tar.xz directory 解压：tar -xJvf archive.tar.xz

zip

压缩单个文件 zip archive.zip example.txt
压缩多个文件 zip archive.zip file1.txt file2.txt file3.txt
递归压缩目录 zip -r archive.zip directory/
压缩并设置密码保护 zip -e archive.zip file.txt
解压缩.zip 文件： unzip archive.zip

scp

将文件example.txt复制到远程主机的/home/user/目录下：scp example.txt user@remote_host:/home/user/
将远程主机上的文件example.txt复制到本地的当前目录：scp user@remote_host:/home/user/example.txt .
递归复制目录，将本地的my_directory目录复制到远程主机的/home/user/目录下： scp -r my_directory user@remote_host:/home/user/

systemctl

启动服务 sudo systemctl start [服务名]
停止服务 sudo systemctl stop [服务名]
重启服务 sudo systemctl restart [服务名]
重新加载配置（不重启服务） sudo systemctl reload [服务名]
查看单个服务状态 systemctl status [服务名]
查看所有运行中的服务 systemctl list-units –type=service –state=running
查看失败的服务 systemctl –failed
启用服务（开机自启） sudo systemctl enable [服务名]
禁用服务（取消开机自启） sudo systemctl disable [服务名]
查看服务是否启用 systemctl is-enabled [服务名]

服务启动失败检查

查看详细日志： journalctl -u [服务名] -xe
检查依赖关系： systemctl list-dependencies [服务名]
在调试模式下运行： systemctl status [服务名] -l –no-pager

man

要查看 ls 命令的手册页面，可以执行以下命令： man ls
要查看 C 语言标准库函数 printf 的手册页面，可以执行： man 3 printf
要搜索包含特定关键字的手册页面条目，可以使用 -k 选项： man -k keyword

ps 用于显示当前进程的状态

查找指定进程格式： ps -ef | grep 进程关键字
显示进程信息： ps -A
显示root进程用户信息： ps -u root
显示所有进程信息，连同命令行： ps -ef
